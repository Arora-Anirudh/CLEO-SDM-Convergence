# Work log - 2026-08-01

## Targeted high-resolution Golovin precision extension

The researcher authorized one fixed follow-up block: add 100 new independent
collision members at each of 262,144 and 524,288 SDs. This produces 150,
150 and 50 members at 262,144, 524,288 and 1,048,576 SDs, respectively. No
new resolution and no new 1,048,576-SD members are included.

The implementation deliberately keeps the prior fixed-50 ladder and
`analysis_v2` immutable. The extension matrix has 200 rows, member indices
50--149, a separate collision-seed namespace, and the original analysis stage
label. Tests verify that its run labels and collision seeds are disjoint from
the completed 450-member fixed-50 matrix.

The two targeted resolutions reuse their existing controlled binary bundles
read-only. That is not accidental reuse of a stochastic realization: the
controlled bundle fixes the initial population, whereas every added member
uses a new collision RNG stream.

New execution and analysis safeguards:

- one 20-worker Slurm allocation, not a 200-job array;
- each active member is one explicit `srun` step with one MPI rank, one thread,
  exclusive shared-allocation memory and physical-core placement; lightweight
  Bash workers do not reserve cores themselves;
- a Stage-0-only job for the subset matrix;
- a checksum-recorded, read-only combined analysis view made of absolute
  symlinks to original completed run directories; and
- a targeted practical analyzer that records unequal member counts rather than
  pretending the 150/150/50 design is balanced.

The extension remains a transparent, prospectively frozen follow-up prompted
by the inspected fixed-50 result. It must not replace the balanced fixed-50
formal decision retrospectively.

Local validation: focused pytest suite 12 passed; Python compilation, Bash
syntax and `git diff --check` passed. The full local suite reported six
pre-existing environment-only failures because the local Python lacks the
project dependency `awkward`; the remaining 101 tests passed. Full checks,
